# Offline Java AI Chat App

A simple offline Android chat application built in Java with XML UI.

What it includes:
- Java + XML Android app
- offline AI response logic
- JSON-based training data
- fast local responses
- no server required

Project structure:
- `app/src/main/java/...` contains the Java code
- `app/src/main/res/layout` contains the UI layout
- `app/src/main/assets/ai_data.json` contains the knowledge base

How to run:
1. Open the project in Android Studio.
2. Let Gradle sync.
3. Build and run on emulator/device.

This is a local offline AI chat app, not a full ChatGPT clone. It is a practical Java-based mobile assistant prototype.
